--- id: export-html
**File ▸ Export output… ▸ HTML (.html)**.

A self-contained report of the Output pane — tables, plots and notes in one file with nothing linked externally, so it opens anywhere and keeps working offline or on a memory stick.

The usual choice for sharing results with someone who does not have CrossTab, and for attaching to a submission. For a document you intend to keep editing, [Word](howto:export-docx) is the better target.
