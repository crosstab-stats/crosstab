Multi-file plugins: can a sandboxed plugin import a second module?

A probe, not a feature. It answers one question before any code gets written — and it exists because the first design for this already collapsed: a blob: URL minted in the host realm carries the host's origin, and a plugin sandbox is an opaque origin, so the frame cannot fetch it.

What is being tested. The frame receives every module's source text and makes its own blobs (same origin, therefore fetchable). The open question is how the entry module then refers to its sibling. Each row below is one answer, run inside a real plugin sandbox: <iframe sandbox="allow-scripts"> with CrossTab's own CSP, default-src 'none'; script-src 'unsafe-inline' blob:; connect-src 'none'. A row can fail for lack of browser support or because the CSP refused it, so the environment block records both.
